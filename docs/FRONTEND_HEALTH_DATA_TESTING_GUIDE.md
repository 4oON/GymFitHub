# 前端健康数据功能测试指南

## 🚀 快速开始

### 1. 启动开发服务器

```bash
# 在项目根目录
cd frontend
npm run dev
```

前端将在 `http://localhost:5173` 启动

### 2. 确保后端运行

在另一个终端：
```bash
cd backend
npm run dev
```

后端将在 `http://localhost:3001` 启动

## 📋 测试步骤

### Step 1: 登录/注册

1. 打开浏览器访问 `http://localhost:5173`
2. 如果没有账号，先注册：
   - 点击 "Register" 或访问 `/register`
   - 输入邮箱和密码
   - 点击注册

3. 登录：
   - 输入邮箱和密码
   - 点击登录

### Step 2: 访问个人资料页面

1. 登录后，访问 `/profile` 或点击 "Profile" 按钮
2. 您会看到个人资料的Bento Grid布局
3. 注意**体脂率卡片**（琥珀色）：
   - 如果没有健康数据，显示 `--`
   - 下方有提示："点击设置健康数据同步"

### Step 3: 进入健康数据设置页面

有两种方式：

**方式1：点击体脂率卡片**
- 直接点击琥珀色的体脂率卡片

**方式2：点击"健康数据"按钮**
- 在页面顶部找到绿色的"健康数据"按钮（心形图标）
- 点击进入

或直接访问：`http://localhost:5173/health-settings`

### Step 4: 启用健康数据同步

1. 在健康数据设置页面，您会看到：
   - **同步状态卡片**（显示"未启用"）
   - 授权状态、最后同步时间等信息
   - "启用健康数据同步"按钮

2. 点击**"启用健康数据同步"**按钮
3. 等待处理（会显示"启用中..."）
4. 成功后：
   - 状态变为"已启用"（绿色）
   - 按钮变为"手动输入数据"、"开启自动同步"、"禁用"

### Step 5: 手动输入健康数据

1. 点击**"手动输入数据"**按钮
2. 在弹出的模态框中：
   - 注意顶部的琥珀色警告框：
     > "注意：手动输入的数据仅保存在ZenFit中，不会同步到iOS健康应用。"
   
3. 输入数据：
   - **体重 (kg)**：例如 `70.5`
   - **体脂率 (%)**：例如 `18.5`
   - **性别**：选择 男/女/其他

4. 点击**"保存数据"**按钮
5. 等待保存（显示"保存中..."）
6. 成功后：
   - 模态框关闭
   - 显示成功消息："健康数据同步成功！"
   - 页面自动刷新数据

### Step 6: 查看健康数据

保存成功后，您会看到**"最新健康数据"**卡片，显示三个数据：

1. **体重卡片**（绿色）
   - 显示您输入的体重
   - 单位：kg

2. **体脂率卡片**（琥珀色）
   - 显示您输入的体脂率
   - 单位：%

3. **性别卡片**（紫色）
   - 显示您选择的性别

底部显示同步时间

### Step 7: 测试自动同步开关

1. 点击**"开启自动同步"**按钮
2. 成功后显示："自动同步已开启"
3. 按钮文字变为"关闭自动同步"
4. 再次点击可以关闭

### Step 8: 返回个人资料页面验证

1. 点击左上角的返回按钮（←）
2. 或直接访问 `/profile`
3. 查看**体脂率卡片**：
   - 现在应该显示您刚才输入的体脂率
   - 右上角有绿色的✓图标（表示已同步）
   - 不再显示"点击设置健康数据同步"提示

## 🎨 UI元素说明

### 健康数据设置页面

#### 1. 同步状态卡片
- **状态指示灯**：
  - 🟢 绿色 = 已启用
  - ⚪ 灰色 = 未启用
- **状态标签**：
  - 绿色徽章 = "已启用"
  - 灰色徽章 = "未启用"

#### 2. 操作按钮
- **启用健康数据同步**（绿色）- 首次使用
- **手动输入数据**（蓝色）- 输入健康数据
- **开启/关闭自动同步**（靛蓝色）- 切换自动同步
- **禁用**（玫瑰色）- 禁用同步功能

#### 3. 信息提示卡片（蓝色）
重点说明：
- ✅ **只读取，不写入**
- ✅ iOS健康应用是唯一数据源
- ✅ 手动输入不会同步到iOS
- ✅ 数据加密存储

### 个人资料页面

#### 体脂率卡片（琥珀色）
- 点击可跳转到健康设置
- 有数据时显示✓图标
- 无数据时显示提示文字

## 🐛 常见问题

### 问题1：无法连接后端
**症状**：点击按钮后显示网络错误

**解决**：
```bash
# 确保后端正在运行
cd backend
npm run dev

# 检查后端是否在 http://localhost:3001
```

### 问题2：登录后跳转到空白页
**症状**：登录成功但页面空白

**解决**：
- 检查浏览器控制台是否有错误
- 尝试手动访问 `/profile`
- 清除浏览器缓存

### 问题3：数据不显示
**症状**：保存数据后卡片仍显示"--"

**解决**：
- 刷新页面
- 检查浏览器控制台Network标签
- 确认API请求成功（状态码200）

### 问题4：模态框不关闭
**症状**：点击保存后模态框不关闭

**解决**：
- 检查是否有错误消息
- 点击"取消"按钮或X关闭
- 刷新页面重试

## 📊 API调用流程

### 启用同步
```
POST /api/health/enable
→ 返回授权状态
→ 更新UI状态
```

### 手动输入数据
```
POST /api/health/sync
Body: { weight, bodyFatPercent, gender }
→ 返回保存的数据
→ 显示在卡片中
```

### 获取最新数据
```
GET /api/health/latest
→ 返回最新健康数据
→ 更新UI显示
```

## 🎓 开发者提示

### 查看API请求
打开浏览器开发者工具（F12）：
1. 切换到 **Network** 标签
2. 筛选 **Fetch/XHR**
3. 执行操作
4. 查看请求和响应

### 查看控制台日志
打开浏览器开发者工具（F12）：
1. 切换到 **Console** 标签
2. 查看是否有错误或警告
3. 检查API调用日志

### 调试技巧
- 使用 `console.log()` 查看状态
- 检查 React DevTools
- 查看 Network 请求详情
- 验证 JWT token 是否有效
