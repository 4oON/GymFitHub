# 刷新干净数据指南

## 问题描述

当你在数据库中清理了脏数据后，前端localhost仍然显示旧的脏数据。这是因为：

1. **浏览器缓存**：前端将数据缓存在 `localStorage` 中
2. **数据不同步**：本地缓存的数据没有自动更新
3. **混合数据**：本地缓存中既有脏数据也有好数据

## 解决方案

使用 [`refresh-clean-data.html`](../frontend/refresh-clean-data.html) 工具来：
- ✅ 清除所有本地缓存
- ✅ 从后端重新加载已清理的干净数据
- ✅ 保留好数据（从数据库重新拉取）
- ✅ 显示清理前后的对比

## 使用步骤

### 第一步：打开工具

在浏览器中打开：
```
http://localhost:5173/refresh-clean-data.html
```

或者直接打开文件：
```
frontend/refresh-clean-data.html
```

### 第二步：输入认证信息

1. 工具会自动尝试从 `localStorage` 获取你的 JWT token
2. 如果没有自动加载，你需要手动输入：
   - 打开浏览器开发者工具（F12）
   - 进入 Console 标签
   - 输入：`localStorage.getItem('token')`
   - 复制返回的 token
   - 粘贴到工具的输入框中
   - 点击"保存Token"

### 第三步：查看数据对比

点击"🔄 刷新对比"按钮，查看：
- **本地缓存数据**：当前浏览器中的数据（包含脏数据）
- **后端干净数据**：数据库中已清理的数据

这样你可以看到有多少脏数据需要清除。

### 第四步：执行刷新

1. 确认数据对比无误
2. 点击"🔄 清除缓存并重新加载干净数据"按钮
3. 确认操作
4. 等待工具完成以下步骤：
   - ✅ 清除本地缓存
   - ✅ 从后端加载训练记录
   - ✅ 从后端加载训练计划
   - ✅ 验证数据完整性

### 第五步：刷新页面

操作完成后：
1. 点击工具中的"🔄 刷新页面查看"按钮
2. 或者按 `F5` 刷新浏览器
3. 查看你的应用，现在应该只显示干净的数据了

## 工作原理

```
┌─────────────────────────────────────────────────────────┐
│  1. 数据库清理（你已完成）                                │
│     DELETE FROM workouts WHERE ...                       │
│     ✅ 数据库现在只有干净数据                             │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  2. 前端缓存问题（当前状态）                              │
│     localStorage['workout-sessions'] = [脏数据 + 好数据]  │
│     ❌ 前端仍显示脏数据                                   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  3. 使用刷新工具                                          │
│     - 清除 localStorage                                  │
│     - 从后端 API 重新拉取数据                             │
│     - 保存到 localStorage                                │
│     ✅ 前端现在只有干净数据                               │
└─────────────────────────────────────────────────────────┘
```

## 数据流程

```javascript
// 清理前
localStorage['workout-sessions'] = [
  { id: 1, date: '2026-01-01', ... },  // 好数据
  { id: 2, date: '2099-12-31', ... },  // 脏数据（未来日期）
  { id: 3, date: '2026-01-02', ... },  // 好数据
  { id: 4, date: null, ... },          // 脏数据（空日期）
]

// 执行刷新工具
1. localStorage.clear()  // 清除所有缓存
2. fetch('/api/workout') // 从后端获取干净数据
3. localStorage.setItem('workout-sessions', cleanData)

// 清理后
localStorage['workout-sessions'] = [
  { id: 1, date: '2026-01-01', ... },  // 好数据
  { id: 3, date: '2026-01-02', ... },  // 好数据
]
```

## 注意事项

### ⚠️ 使用前确认

1. **已清理数据库**：确保已在数据库中执行清理脚本
2. **已保存token**：确保有有效的 JWT token
3. **无未同步数据**：确保没有重要的未同步数据

### ✅ 安全保障

- 工具会保留你的登录状态（JWT token）
- 所有数据都从后端重新加载，不会丢失好数据
- 提供清理前后的数据对比
- 显示详细的操作日志

### 🔍 验证结果

刷新后，检查：
1. 训练记录数量是否正确
2. 是否还有脏数据（未来日期、空日期等）
3. 好数据是否都保留了

## 其他清理工具

如果你只想清除缓存而不重新加载：

### 1. 使用现有的清理工具
打开 [`clear-local-cache.html`](../frontend/clear-local-cache.html)

### 2. 使用浏览器开发者工具
```javascript
// 打开 Console (F12)
localStorage.clear()
location.reload()
```

### 3. 使用浏览器设置
- Chrome: 设置 → 隐私和安全 → 清除浏览数据
- 选择"Cookie 和其他网站数据"
- 选择"缓存的图片和文件"

## 常见问题

### Q: 刷新后数据还是不对？
A: 
1. 确认数据库确实已清理
2. 检查后端 API 是否正常：`http://localhost:3000/api/workout`
3. 查看浏览器 Console 是否有错误
4. 尝试完全重启浏览器

### Q: Token 在哪里找？
A:
```javascript
// 方法1：从 localStorage 获取
localStorage.getItem('token')

// 方法2：重新登录
// 登录后会自动保存到 localStorage
```

### Q: 会丢失数据吗？
A: 不会。工具会从后端重新加载所有数据，只要数据在数据库中，就不会丢失。

### Q: 可以只刷新训练记录吗？
A: 可以。修改工具代码，注释掉训练计划的部分即可。

## 技术细节

### API 端点
- `GET /api/workout` - 获取所有训练记录
- `GET /api/routine` - 获取所有训练计划

### localStorage 键
- `token` - JWT 认证token
- `workout-sessions` - 训练记录数组
- `routines` - 训练计划数组

### 认证方式
```javascript
fetch('/api/workout', {
  headers: {
    'Authorization': `Bearer ${token}`
  }
})
```
