# SVG Path Editor - 视图类型编辑功能测试指南

## 🎯 测试目标

验证 SVGPathEditor 的视图类型编辑功能是否正常工作，特别是修正三头肌（triceps）从正面视图移到背面视图的问题。

## 📋 测试前准备

### 1. 启动应用
```bash
npm run dev
```

### 2. 打开 SVG Path Editor
1. 在浏览器中打开应用
2. 点击右上角的开发者工具按钮
3. 点击**紫色的编辑图标**（Edit3）打开 SVGPathEditor

## 🧪 测试用例

### 测试用例 1: 查看当前问题

**目的：** 确认三头肌确实出现在错误的视图中

**步骤：**
1. 在 SVGPathEditor 中，确保选择"正面"视图
2. 观察画布上显示的肌肉
3. 查找三头肌（triceps）- 它应该在手臂后侧

**预期结果：**
- ⚠️ 三头肌出现在正面视图中（这是错误的）
- 三头肌的路径应该是可见的

---

### 测试用例 2: 修改视图类型

**目的：** 测试视图类型切换功能

**步骤：**
1. 在"正面"视图中，点击 `triceps` 肌肉区域
2. 右侧面板应该显示肌肉信息
3. 找到"视图类型 (View Type)"下拉框
4. 当前应该显示"正面 (Front)"
5. 将其改为"背面 (Back)"

**预期结果：**
- ✅ 下拉框成功切换到"背面 (Back)"
- ✅ 出现蓝色的"视图已更改"标签
- ✅ 显示原始视图信息

---

### 测试用例 3: 验证实时预览

**目的：** 确认视图切换后立即生效

**步骤：**
1. 在修改 triceps 视图类型为"背面"后
2. 保持在"正面"视图
3. 观察 triceps 是否还在画布上
4. 点击顶部的"背面"按钮切换视图
5. 观察 triceps 是否出现

**预期结果：**
- ✅ triceps 从正面视图消失
- ✅ triceps 在背面视图出现
- ✅ 其他肌肉保持不变

---

### 测试用例 4: 导出配置

**目的：** 测试导出功能是否包含视图类型信息

**步骤：**
1. 确保 triceps 的视图类型已改为"背面"
2. 点击"导出配置文件"按钮
3. 下载文件 `triceps_updated_[timestamp].ts`
4. 打开下载的文件

**预期结果：**
文件应包含视图类型更新说明

---

### 测试用例 5: 同时修改路径和视图

**目的：** 测试同时修改路径和视图类型

**步骤：**
1. 选择任意肌肉（例如 chest）
2. 修改 SVG path 数据
3. 同时将视图类型从"正面"改为"背面"
4. 观察变化指示器

**预期结果：**
- ✅ 显示两个标签：黄色"路径已修改" + 蓝色"视图已更改"
- ✅ "导出配置文件"按钮可用
- ✅ 底部显示"将导出: 路径 + 视图类型"

---

### 测试用例 6: 重置功能

**目的：** 测试重置按钮

**步骤：**
1. 修改某个肌肉的视图类型和路径
2. 点击"重置所有修改"按钮

**预期结果：**
- ✅ 视图类型和路径都恢复到原始值
- ✅ 所有变化指示器消失

---

### 测试用例 7: 多个肌肉切换

**目的：** 测试状态保存

**步骤：**
1. 选择 triceps，将视图改为"背面"
2. 选择 biceps，将视图改为"背面"
3. 切换回 triceps

**预期结果：**
- ✅ triceps 的视图类型仍然是"背面"
- ✅ 显示"视图已更改"标签
