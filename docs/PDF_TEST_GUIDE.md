# PDF排版修复测试指南

## 测试目的
验证PDF排版修复是否正确应用，确保所有问题得到解决。

## 测试方法

### 方法1：使用独立HTML测试文件（推荐）

1. **打开测试文件**
   ```bash
   # 在浏览器中打开
   test_pdf_layout.html
   ```
   或者直接双击文件在浏览器中打开

2. **查看测试页面**
   - 页面右上角有测试控制面板
   - 红色虚线显示19mm（0.75英寸）边距
   - 可以看到应用了所有修复的样式

3. **测试功能**
   - 点击"打印/导出PDF"按钮
   - 在打印对话框中选择"另存为PDF"
   - 保存并检查生成的PDF

4. **测试长文本**
   - 点击"测试长文本"按钮
   - 查看表格是否正确处理超长内容
   - 再次导出PDF验证

5. **检查项目**
   - ✅ 页面边距为19mm（0.75英寸）
   - ✅ SVG图形无文字溢出
   - ✅ 表格内容限制在单元格内
   - ✅ 长文本自动截断显示省略号
   - ✅ 字体大小符合规范（8pt表格，16pt标题）

### 方法2：重新编译前端应用

1. **停止当前运行的开发服务器**
   ```bash
   # 按 Ctrl+C 停止
   ```

2. **清理并重新安装依赖**
   ```bash
   cd frontend
   npm run build
   ```

3. **重新启动开发服务器**
   ```bash
   npm run dev
   ```

4. **在应用中测试**
   - 创建或打开一个训练记录
   - 导出PDF报告
   - 检查生成的PDF是否应用了修复

### 方法3：强制刷新浏览器缓存

如果修改没有生效，可能是浏览器缓存问题：

1. **清除缓存**
   - Chrome/Edge: `Ctrl + Shift + Delete`
   - Firefox: `Ctrl + Shift + Delete`
   - Safari: `Cmd + Option + E`

2. **硬刷新页面**
   - Windows: `Ctrl + F5` 或 `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`

3. **重新导出PDF**

## 常见问题排查

### 问题1：修改没有生效
**原因**：浏览器缓存或应用未重新编译

**解决方案**：
1. 清除浏览器缓存
2. 硬刷新页面（Ctrl+Shift+R）
3. 重新编译前端应用
4. 使用独立HTML测试文件验证

### 问题2：表格内容仍然溢出
**原因**：文本过长或列宽设置不当

**解决方案**：
1. 检查是否使用了最新的HTMLTemplateService.ts
2. 确认表格CSS包含 `table-layout: fixed`
3. 确认单元格CSS包含 `max-width: 0`
4. 使用测试文件的"测试长文本"功能验证

### 问题3：SVG文字仍然溢出
**原因**：旧版本代码仍在使用SVG text元素

**解决方案**：
1. 确认generateMuscleGroupSVGs函数已移除text元素
2. 检查是否有其他地方添加了SVG文字
3. 使用独立测试文件验证（无SVG文字）

### 问题4：页面边距不正确
**原因**：打印设置或CSS未正确应用

**解决方案**：
1. 检查@media print规则
2. 确认@page设置为 `margin: 0.75in`
3. 在打印对话框中检查边距设置
4. 使用测试文件的边距指示器验证
